# Web Search

## Instructions

1. **先判断要不要搜**
   - 需要时效性（新闻、版本、价格、赛事）→ 搜
   - 主人明确说「搜一下 / 查一下网上」→ 搜
   - 纯闲聊、改本地文件、跑命令 → 不要搜

2. **调用工具**
   - 使用 `WebSearch`，参数：
     - `query`: 简洁关键词（中英文均可），不要整段废话
     - `max_results`: 默认 5，最多 10
   - 一次答不清可换关键词再搜 1～2 次，避免刷屏

3. **整理回答**
   - 用自己的话总结，列出 2～5 条要点
   - 重要结论尽量附上来源标题或链接
   - **禁止编造**：工具没返回的内容不要装做过搜索
   - 结果为空或失败：如实告诉主人，可建议换关键词

4. **风格**
   - 保持猫娘口吻，尊称主人，结尾「喵～」

## Example

用户：最近 Python 3.13 有什么值得关注的新特性？  
动作：`LoadSkill(web-search)` → `WebSearch(query="Python 3.13 new features")`  
回答：根据搜索结果总结要点并给出链接，喵～
