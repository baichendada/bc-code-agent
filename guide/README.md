# 从零写一个终端 Agent（20 步）

这个目录是一份"跟着敲就能写出来"的教程：从一个只会说一句话的程序开始，一步步长成一个能在终端里读写文件、跑命令、查资料、管记忆、派子 Agent、定时干活的完整 Agent。

主仓库的 `src/bc_code_agent/` 是完整实现；这里每一步提供一个**教学裁剪版**——代码更短、只保留当步需要的骨架，但每一步都能独立运行。

## 怎么用

- 按顺序读，每章 15–30 分钟能做完
- 每步一个目录，里面的 `agent.py` 可直接跑：

```bash
python guide/step-01-hello-agent/agent.py
```

- 跑通每章的"验收标准"再进入下一步
- 想看完整版随时对照 `src/bc_code_agent/`

## 环境（只需准备一次）

Python 3.10+，在项目根目录执行：

```bash
pip install -r requirements.txt
```

创建 `.env`（已 gitignore，永远不要提交）：

```bash
ANTHROPIC_AUTH_TOKEN=your-token
ANTHROPIC_BASE_URL=https://open.bigmodel.cn/api/anthropic
ANTHROPIC_MODEL=glm-5.2
MAX_TOKENS=10000
```

## 每章的固定结构

1. **本步目标**：你要做出什么，跑起来长什么样
2. **准备**：需要的前置知识和环境
3. **原理**：为什么需要这个东西，解决上一章的什么痛点
4. **动手实现**：代码一小块一小块地写，每块都讲清楚
5. **完整代码**：本章 `agent.py` 全文
6. **运行与验收**：怎么跑、达到什么标准算学会
7. **常见坑**：报错对照表
8. **下一步预告**：留个钩子

## 写作三原则

1. **一步只引入一个新概念**。工具调用那章就不谈记忆，记忆那章就不谈工具，读者的大脑一次只消化一件事。
2. **代码是主角**。每章的 `agent.py` 是上一章的最小增量， diff 一眼看得出"这章加了什么"；文字围着代码走，不搞论文式长篇。
3. **跑通才算学会**。每章必须有可验收的运行结果，不接受"理论上应该可以"。
